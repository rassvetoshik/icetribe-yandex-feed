# YML-фид IceTribe для Яндекс Директа

Репозиторий автоматически строит отдельный YML-фид из [исходного фида Tilda](https://icetribe.ru/tstore/yml/6aaa63d2ffe6f090367e6716269e1ab6.yml) и публикует его через GitHub Pages.

Публичный адрес после первого успешного запуска:

`https://rassvetoshik.github.io/icetribe-yandex-feed/yandex-direct.yml`

Отдельный фид для блока «Страницы каталога» в Директе:

`https://rassvetoshik.github.io/icetribe-yandex-feed/catalog-pages.yml`

## Что попадает в фид

- 5 вариантов инфракрасной сауны с ПЭМП — с цветом и размером в названии;
- 3 ванны для закаливания;
- инфракрасная кепка для роста волос;
- Энерджи ПЭМП-мат, Офис ПЭМП-мат и ПЭМП-пояс;
- Супер Редлайт и Мега Редлайт;
- LED-щётка с двумя сменными насадками.

Количество предложений меняется автоматически: в публикацию попадают только согласованные товары, которые присутствуют в исходном Tilda-фиде и имеют положительный остаток. Для каждого сохраняются исходные `offer id`, актуальная цена, URL, изображения и другие параметры. Меняются только состав фида и названия товаров.

Если Tilda перестаёт передавать согласованный товар либо передаёт `available="false"` или нулевой `<count>`, товар исключается из обоих обновляемых файлов. Он возвращается автоматически после появления положительного остатка. Ссылки на оба фида при этом остаются прежними.

В `catalog-pages.yml` те же доступные предложения дополнительно привязаны к шести реальным разделам страницы `https://icetribe.ru/katalog`: ванны, ПЭМП-маты, инфракрасные сауны, кепка, LED-щётка и панели красного света. Этот файл содержит обязательные для Директа элементы `<collections>` и `<collectionId>`.

## Обновление

GitHub Actions пересобирает фид каждый час в 17 минут после часа и при каждом изменении основной ветки. При невозможности получить исходный фид или полном отсутствии согласованных товаров в наличии сборка завершается ошибкой и сохраняет последнюю рабочую публикацию.

## Локальная проверка

```bash
npm test
npm run build
```

Результаты локальной сборки: `docs/yandex-direct.yml` и `docs/catalog-pages.yml`.
